# Reachly — The living line

**Direction:** continuous visual journey, not a stack of decorated sections. Revision of the dual-experience art direction, grounded in the owner's critique. Baseline: `ee20d525d34f3ebd61e4c5e2f81f9cceb80baa35`.

## The structural change

Studio remains a Decide/Learn surface, but its composition is an authored passage through a shared world. Possibilities is the Explore surface of that same world. The previous site had substantial headings, isolated SVG ornaments and abrupt surface changes; changing their easing would not resolve the owner's criticism. Replace the primary journeys' composition and animation architecture, while retaining truthful project/service content and ordinary supporting routes.

## One world: a point finds its way

A signature lime point becomes a broad, tactile ribbon. It turns, folds, opens a frame, carries real work, makes connections, and points beyond the screen. An ivory atelier is the daytime Studio world; a deep-green space is its exhibition counterpart. These are alternate lighting states/material exposures, not unrelated visual systems.

The continuous graphic has a stable identity across every chapter. It is a spatial object, not a different ornamental SVG above each heading. Camera position, ribbon geometry and foreground composition change together. Directional curves, punched circles, thin drafting lines, coordinate marks and the moving lime point recur as one graphic grammar. The official logo remains untouched.

## Scroll narrative / Studio

1. **Origin:** the visitor lands inside the ivory atelier. A large original ribbon sculpture dominates the frame; concise business copy and an immediate inquiry link sit beside it. The point and sculpture establish the visual protagonist before the first scroll.
2. **Presence:** the ribbon unfurls from the opening into a wide aperture. Real client website imagery begins inside it and drifts into an unequal, layered portfolio arrangement. No background reset; project images appear to belong to the same visual space. Every project remains a normal accessible link.
3. **Capability:** the same line broadens and branches into five paths. Each branch has a practical service label and a concise explanation; services are an annotated graphic system, not another stack of feature cards. All five approved names remain visible and linked.
4. **Connection:** the branches return to one path. Five process stops lie along it: Discover, Plan, Create, Launch, Improve. Progress and the point carry forward from the preceding scene; there is no independent process intro animation.
5. **Possibility:** camera/world expand and the line crosses toward the darker exhibition. A window into the same world invites exploration without stealing the commercial path.
6. **Resolution:** the line folds into an outgoing gesture and ends beside the project invitation. The beginning and ending share the same point, making the closing action the narrative destination.

## Scroll narrative / Possibilities

A tighter camera, deeper green environment and more expansive graphic scale expose the same sculpture. The point travels along a continuous curve; the loop opens into actual work; that curve becomes the sample handoff pathway; its nodes resolve into a further-reaching gesture. Perspective controls alter the shared object, not swap unrelated animations. The sample workflow remains explicitly illustrative and never sends or stores data.

## Persistent asset system

- **Sculptural ribbon:** authored deformable 3D geometry, broad lime face and deep-green edge; one mesh identity across the journey, supported by a coherent SVG/static fallback.
- **World plates:** original generated ivory-atelier wide image and matching macro passage. Used as material/environment layers within the same composition, not separate full-screen chapter posters.
- **Real work planes:** the four verified captures, with honest dimensions and captions; no invented screen UI or client outcomes.
- **Drafting layer:** original route contours, registration circles, arrow apertures, branch diagrams and point trails. Reusable shapes share stroke weights and transform around the same coordinates.
- **Sample handoff nodes:** use the world's point/path vocabulary instead of disconnected UI tiles.

Generated artwork is labelled in provenance as conceptual brand imagery, never project work. Reference assets/brands are not redistributed.

## One motion score

Use native document scrolling as the input to one scene state. Normalize the positions of meaningful chapter landmarks; interpolate poses through shared handoff intervals. Geometry, world orientation, camera composition, background layers and accent point sample that same state. No independent randomized entrances. Reversing scroll reverses the authored sequence without accumulating states.

The motion verbs are **trace → unfold → frame → branch → reconnect → extend**. Path deformation is the main transformation; drifting imagery, depth changes and small pointer response are subordinate. Strong holds allow people to read. Adjacent scenes deliberately overlap rather than jumping on section boundaries.

The persistent world is non-interactive behind semantic HTML; it cannot intercept scrolling, steal pointer input from links or trap focus. Image planes/labels remain readable regardless of camera state. Pause freezes expressive world motion while native content navigation continues. System reduced motion and renderer failure reveal meaningful static artwork and ordinary content. Resize, visibility, context loss, direct fragments and browser Back must preserve the journey.

## Prototype and implementation acceptance

The revised actual pages are the visual prototype, not a separate unrelated mockup. First prove the persistent world and at least three transitions; inspect them at intermediate scroll positions before extending the score. Then integrate the full content and remaining scenes.

Required evidence: the same world DOM/renderer survives multiple chapters; adjacent state samples remain continuous; forward/reverse scrolling updates visible transforms; real assets load; all client/service/inquiry links work; no document overflow at mobile/desktop/wide sizes; reduced-motion/no-JS/failed-renderer paths remain readable. Test the new behavior before implementation and retain validation/privacy/navigation guarantees. Old isolated-ornament screenshot assertions are deliberately obsolete, not business requirements.
