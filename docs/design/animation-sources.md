## Behavior boundaries
- Native document scrolling, no Lenis or wheel hijacking. Horizontal client controls and keyboard focus override scroll assistance for that motion installation.
- Desktop pinning only (1000px+); mobile uses native rail browsing and vertically readable process steps.
- Pause, reduced motion and missing GSAP remove pins and masks; all five process stages remain readable. WebGL failure exposes the CSS pavilion.
- Off-screen/hidden-page canvas animation stops. Approved branding, five services, four exact client links and local-only planner are retained.
- Full-bleed hero with a bounded 1760px device plane prevents ultra-wide perspective clipping. Miniature type scales to its own browser container.
